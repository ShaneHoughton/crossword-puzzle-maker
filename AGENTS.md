# Agent Guidelines

- Do not update README files as part of implementation changes; they are for human readers. Only modify them when explicitly asked.

## AI collaboration

- Use judgment for small choices; ask before significant behavior, UX, or architecture decisions.
- Ask before adding dependencies.
- Run relevant lint, type-check, and test commands for each change.
- Do not commit or push unless explicitly asked.
- Use only approved tools and services. Never share secrets or sensitive project data.
